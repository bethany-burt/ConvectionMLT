Why it failed
-------------
This is a Stage 4 core / coupling problem first, a HELIOS problem second.

1. Formal convergence was not required before auditing.
   Tests and the first dossier accepted stalled and max_steps terminals as if they were RCE.
   The plan requires simultaneous flatness, tendency, dT, RCB stability, and a finite state for N_consec accepted steps.
   A max_steps or stalled run is not evidence.

2. Manufactured T* attraction is not unique without extra restoring physics.
   Frozen F_rad* = F0 - F_conv(T*) is a fixed point (identity passes).
   For T* ~ P^beta, a multiplicative hot/cold shift nearly preserves nabla, so F_conv barely changes and there is little restoring force on T itself.
   The first restoring term used q = -kappa (T - T*) with kappa = 1e-3, which is an enthalpy rate of kappa * dT. With cp ~ 1e4 J kg^-1 K^-1 the thermal time was ~ cp/kappa ~ 1e7 s. Attraction could not finish.

3. Split rad->conv could accept a no-op.
   On ThermoDomainError the macrostep returned the original committed state (finite), and the outer loop treated that as success.
   Rad-then-conv therefore often did not advance while conv-then-rad did. That produced the 1.73 vs 2e-4 split asymmetry.

4. Manufactured final fluxes were overwritten by a real RT solve.
   After a manufactured run, rad is None, so the epilogue called solve_radiation and replaced F_rad* with grey two-stream fluxes.
   Flatness then looked ~1 even when the manufactured operator was fine.

5. Energy residual used stored enthalpy differences.
   h_new = h_old + dt * dh/dt loses the O(dt) update against large |h| in float64.
   Dividing that residual by |boundary work| ~ 0 near equilibrium inflated the reported 6.7e-8.

6. Real grey RCE from the 0.58 power-law IC is violently convective.
   F_conv max ~ 1e9 W m^-2. Flux is not flat after a short run. LowerFlux sets F_up, not net flux, so F_net at the bottom is ~ 300 - sigma T^4 ~ -3e4 W m^-2 on a 900 K profile. The column is not at RCE.

7. Live HELIOS was not a matched comparison.
   MLT used grey kappa = 2e-4, g = 15, LowerFlux(300), TopIrradiation(120), N = HELIOS layer count.
   HELIOS used its default k-table case (r50_kdistr_solar_eq.h5), Teff ~ 679 K, Tint = 30 K, its own grid/EOS/opacity.
   Differences near unity are expected for unmatched setups. The plan forbids freezing 37-38 gates from that.

8. Point 38 was only a Boolean.
   finite_flux: true and a sign check do not measure convection-off recovery.
   The live file path was an absolute cluster path with no checksum and no (observed, scale, tolerance, status) row.
