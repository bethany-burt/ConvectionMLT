R0 DEBUG AND BUG-FIX RECORD
===========================

Fix ID: R0-S1-001
Date: 2026-08-09
Stage: Stage 1 - Closed dry-H2 convective column
Status: Fixed and regression-tested
Title: Localized mixed region incorrectly tested against a global adiabat

SUMMARY
-------
The localized-convection robustness case evolved to negligible
superadiabaticity and temperature tendency while conserving column enthalpy,
but the solver continued until max_steps and returned "failed".

This was a convergence-diagnostics/reference-state bug. It was not a defect in
the MLT flux or conservative energy update.

OBSERVED FAILURE
----------------
Before the fix, the localized case reached:

  max superadiabaticity       = 1.72e-15
  max normalized tendency     = 6.54e-25 s^-1
  relative enthalpy drift     = 0
  max global-reference T error = approximately 3.1e-2
  terminal status             = failed
  accepted steps              = 1,000,000

The tiny gradient and tendency showed that the active region had stopped
evolving. The nonzero temperature error came from comparing the whole column
with one global enthalpy-normalized adiabat.

ROOT CAUSE
----------
A global reference adiabat is valid only when the mixed region is connected.
Stable interfaces prevent dry MLT from exchanging enthalpy between separated
regions. Each connected region therefore conserves its own enthalpy and can
reach an adiabat with a different normalization.

An initial static piecewise partition was also insufficient. An interface that
starts stable can later become actively convective. Once enthalpy has crossed
that interface, the adjacent regions must be treated as one combined region.
Keeping the original labels produced a stale reference normalization.

FIX
---
1. Label layers connected through actively unstable interfaces.
2. Construct a separate enthalpy-normalized reference adiabat for each region.
3. Evaluate potential-temperature spread within each region rather than across
   stable barriers.
4. During evolution, merge two regions whenever their separating interface
   becomes actively unstable:

       delta_j > c_active * epsilon_gradient

5. After a merge, recompute the combined region's reference from the original
   initial temperatures and combined initial enthalpy.
6. Never split a region after merging, because prior enthalpy exchange means
   the two original regional budgets are no longer independent.
7. Do not project temperatures onto the reference. The reference remains a
   convergence diagnostic only.

DOCUMENTATION RULE
------------------
A single enthalpy-normalized reference adiabat must only be used for a globally
connected mixed region. A column containing stable barriers must use one
enthalpy-normalized reference per connected mixing region. Region connectivity
may grow during evolution when an interface becomes actively convective.

FINAL AUDIT ADDENDUM
--------------------
Audit date: 2026-08-09; commit-order correction 2026-08-10
Tests after audit: 46 passed

Merge timing:
  Candidate active-interface merges are computed from the accepted pre-step
  state before trial construction. Labels and reference are committed only
  inside the trial.accepted branch, and before cumulative-transfer accounting,
  so active-before/neutral-after interfaces remain correctly merged when a step
  is accepted. Rejected trials, max_steps=0 terminals, and no_active_convection
  exits leave labels and transfer unchanged.

Sub-threshold transport:
  For each still-unmerged internal interface, accepted updates accumulate

      Q_j = sum_n F_conv,j^n * dt_n.

  Q_j is divided by the smaller initial enthalpy of the two adjacent current
  regions. The provisional transfer_merge_tolerance is 1e-9, one tenth of the
  1e-8 relative temperature RMS tolerance. Exceeding it merges the regions.
  The cumulative transfer, final labels, and maximum surviving unmerged
  transfer fraction are stored in every integration result and campaign JSON.

  In the refreshed localized pilot, the largest surviving unmerged transfer
  fraction is 7.035817076352645e-18, comfortably below 1e-9.

Reference conservation:
  Every initial or rebuilt piecewise reference is checked region by region.
  Relative initial-versus-reference enthalpy residual must remain below
  64*machine_epsilon; otherwise the solver raises ArithmeticError.

Reference remains secondary:
  Converged status requires superadiabaticity, normalized tendency, absolute
  convective flux, relative potential-temperature spread, relative temperature
  error, and enthalpy drift to pass independently. The provisional absolute
  convective-flux tolerance is 5e-3 W m^-2, set just above the measured
  float64 pilot floor of approximately 4.2e-3 W m^-2. An all-singleton
  partition cannot establish convergence through trivial reference agreement;
  an exactly stationary stable case instead returns no_active_convection.

Refined wording:
  Each region conserves its own enthalpy while the flux through its separating
  interfaces is zero or negligible within the diagnostic tolerance. Once
  appreciable transport occurs, the connected regions are merged and their
  combined initial enthalpy determines the new reference normalization.
